# YOG / SATTVA

Интерактивное пространство для обсуждения продукта: кликабельный прототип Telegram Mini App, Jobs to Be Done, CJM, User Flow и концепция в одном интерфейсе.

Основа — первый выбранный чёрно-белый макет. SATTVA — личные практики и внутренний баланс; YOG — практики, которые объединяют близких, команды и бренды. Общее «Моё» хранит демозаписи, курсы и избранное.

## Запуск

Node.js 24 и npm 11. Все команды из корня репозитория:

```sh
npm ci --cache /tmp/sattva-npm-cache --no-audit --no-fund
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

```sh
npm run build
npm run preview -- --host 0.0.0.0 --port 4174 --strictPort
```

`npm test` проверяет основные клиентские пути через Playwright на уже запущенном сервере 4173. Используется системный Chromium `/usr/bin/chromium`; можно задать `CHROMIUM_PATH`. Проверки и скриншоты сохраняются в игнорируемой папке `artifacts/`.

## Публикация на GitHub Pages

В репозитории: Settings → Pages → Build and deployment → Source: GitHub Actions. Workflow `.github/workflows/pages.yml` собирает и публикует `dist` после push в `main`. Итоговый адрес берётся из результата workflow, не считается активным до успешного deploy. Для частного репозитория доступность Pages зависит от тарифного плана GitHub.

## Что можно пройти

- подбор практики по цели и времени, каталог, текстовый демоплеер;
- мастер → услуга → слот → демонстрационная запись;
- онлайн-/офлайн-расписание → билет → отмена;
- мини-курс → бесплатный фрагмент / демопокупка → уроки;
- YOG → формат → бриф → локальная демозаявка;
- материалы Telegram, избранное, черновик авторского курса;
- JTBD с фильтрами, CJM с переключением путей, User Flow с переходом в прототип.

Это демонстрация, не рабочая коммерческая платформа. Реальных оплат, бронирований, отправки заявок, загрузки курсов и связи с Telegram нет. Карта и личные контакты не запрашиваются. Материалы, мастера, адреса, цены и расписание демонстрационные. Данные сохраняются только в localStorage этого браузера. Удаление данных сайта удаляет деморезультаты.
